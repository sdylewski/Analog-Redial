# Analog Redial v6 (in progress)

**Not built or tested yet. Build v5 for now** (`../Analog Redial v5/`).

This is the next-generation board. The design is here so you can follow along,
but it is a work in progress and may change: don't order it, and don't assume it
works until the [Get a board](../../../docs/board.md) page says v6 has been
tested.

What it changes from v5, as designed (all untested):

- The clone-module footprint is corrected. On v5 the 30-pin clone's
  bottom-right 5V pin is wired to GND; v6 fixes that.
- The Bluetooth header's 3.3 V regulator becomes a 3.6 V part.
