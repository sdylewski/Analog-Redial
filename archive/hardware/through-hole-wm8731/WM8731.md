# WM8731 — pinout and functional sections

Reference for the **rotary phone gateway** schematic (KiCad symbol **U1**, Wolfson WM8731 Rev 3.4).  
Datasheet: `datasheets/WM8731_Wolfson_audio_CODEC.pdf`  
System context: `SIGNAL_LEVELS.md`

Pin numbers below match the common **28-pin SSOP / KiCad `Audio_WM8731`** style symbol (left column = pins 1–14, right column = pins 15–28). Always confirm against your footprint — **signal names** matter more than absolute pin index if the symbol is rotated.

---

## What the chip does (four blocks)

```text
                    ┌─────────────────────────────────────────┐
  I²C / SPI         │  CONTROL (SDIN, SCLK, MODE, CSB)        │
  (configure) ───►│  Registers, volume, mute, power mgmt    │
                    └─────────────────────────────────────────┘
                                      │
                    ┌─────────────────▼───────────────────────┐
  I²S (BCLK,       │  DIGITAL AUDIO INTERFACE                 │
  LRCK, data) ◄──►│  ADC ◄──► filters ◄──► DAC              │
  MCLK)            │  (stereo 16–32 bit, 8–96 kHz)           │
                    └─────────────────────────────────────────┘
                         │                    │
              analog in  │                    │  analog out
                         ▼                    ▼
                    ┌─────────┐         ┌─────────┐
  LLINEIN/RLINEIN   │  ADC    │         │  DAC    │  LOUT/ROUT
  MICIN (optional)  │  path   │         │  path   │  LHPOUT/RHPOUT
                    └─────────┘         └─────────┘
```

| Block | Pins (group) | Role |
|-------|----------------|------|
| **Supplies** | DCVDD, DBVDD, AVDD, HPVDD, AGND, DGND, HPGND | Multiple rails — not interchangeable |
| **Digital audio (I²S)** | BCLK, DACDAT, DACLRC, ADCDAT, ADCLRC, XTI/MCLK, XTO, CLKOUT | Stereo PCM to/from the MCU |
| **Control bus** | SDIN, SCLK, MODE, CSB | I²C (or 3-wire SPI) setup |
| **Line I/O** | LOUT, ROUT, LLINEIN, RLINEIN | **Used** for SLIC ↔ phone (this project) |
| **Headphone I/O** | LHPOUT, RHPOUT, HPVDD, HPGND | On-chip headphone amp — optional |
| **Microphone I/O** | MICIN, MICBIAS | Electret mic path — **not used** in gateway |

## Supply pins — why there is both 3.3 V and 1.8 V

The WM8731 splits **digital core** from **digital I/O buffers** and **analog** circuits.

| Pin | Name | Typical rail | Powers |
|-----|------|--------------|--------|
| **27** | **DCVDD** | **1.5–1.8 V** (typ 1.5 V) | Internal digital core logic only |
| **1** | **DBVDD** | **3.3 V** | Digital pins: I²S + control (I/O buffers) |
| **14** | **AVDD** | **3.3 V** | Analog: line in/out, ADC/DAC analog section |
| **8** | **HPVDD** | **3.3 V** | Headphone driver (tie even if HP outputs unused) |
| **15** | **AGND** | GND | Analog ground |
| **28** | **DGND** | GND | Digital ground |
| **11** | **HPGND** | GND | Headphone ground |

**Rules (datasheet):**

- **DCVDD ≤ AVDD** always (e.g. 1.8 V core + 3.3 V analog is OK).
- **AGND** and **DGND** must stay within **0.3 V** of each other (star ground on PCB).
- Do **not** connect **DCVDD** to **+3V3** — use an **LDO** (e.g. MCP1700-1.8) from +3V3 → net `DCVDD_1V8` → pin 27 only.
- Absolute max on supply pins: **3.63 V** — design at **3.3 V nominal**.

**+3V3** on the board is still your main rail (ESP32, SLIC, WM8731 analog and I/O). **1.8 V** is an extra net for **one pin** (DCVDD), not a replacement for 3.3 V.

## Digital audio interface (I²S to ESP32)

Slave mode is typical: **ESP32 is I²S master**, WM8731 follows **BCLK** / **LRCK**.

| Pin | Name | Direction (slave) | Connect to ESP32-C6 (this project) |
|-----|------|-------------------|-------------------------------------|
| **3** | **BCLK** | In/out | **GPIO4** — `I2S_BCLK` |
| **5** | **DACLRC** | In/out | **GPIO5** — `I2S_LRCK` (word clock) |
| **7** | **ADCLRC** | In/out | **Tie to DACLRC** (pin 5) for standard I²S |
| **4** | **DACDAT** | In | **GPIO6** — `I2S_DOUT` (MCU → codec playback) |
| **6** | **ADCDAT** | Out | **GPIO7** — `I2S_DIN` (codec → MCU record) |
| **25** | **XTI/MCLK** | In | **GPIO0** — `I2S_MCLK` *or* crystal on XTI/XTO |
| **26** | **XTO** | Out | Crystal feedback only (if using crystal) |
| **2** | **CLKOUT** | Out | Optional clock monitor — usually **NC** |

**Note:** Pin names **DACDAT** / **ADCDAT** are from the **codec’s** point of view: **DACDAT** is data **into** the DAC (from MCU). **ADCDAT** is data **out** of the ADC (to MCU).

## Control interface (I²C to ESP32)

| Pin | Name | Required? | Connection |
|-----|------|-----------|------------|
| **23** | **SDIN** | **Yes** | **GPIO22** — I²C **SDA** (+ 4.7 kΩ pull-up to +3V3) |
| **24** | **SCLK** | **Yes** | **GPIO23** — I²C **SCL** (+ 4.7 kΩ pull-up to +3V3) |
| **21** | **MODE** | **Yes** | **GND** = I²C mode (pull-up internally when inactive) |
| **22** | **CSB** | **Yes** | **GND** or **+3V3** = I²C address bit (0x1A vs 0x1B) |

**MODE** strap:

| MODE | CSB | Bus |
|------|-----|-----|
| GND | GND | 2-wire I²C, address 0x1A |
| GND | VDD | 2-wire I²C, address 0x1B |
| VDD | — | 3-wire SPI (not used here) |

Configure sample rate, volume, mute, and ADC/DAC routing over I²C after reset.

## Analog outputs

| Pin | Name | Used in gateway? | Role |
|-----|------|------------------|------|
| **12** | **LOUT** | **Yes** | Left DAC → phone line 1 (via **100 nF** to AG1170 **VIN**) |
| **13** | **ROUT** | **Yes** | Right DAC → phone line 2 (via **100 nF** to AG1170 **VIN**) |
| **9** | **LHPOUT** | No | Left headphone driver output |
| **10** | **RHPOUT** | No | Right headphone driver output |

Full-scale line out ≈ **1.0 Vrms** at **AVDD = 3.3 V** (into ~10 kΩ). AC coupling to SLIC per Silvertel / `SIGNAL_LEVELS.md`.

## Analog inputs

| Pin | Name | Used in gateway? | Role |
|-----|------|------------------|------|
| **20** | **LLINEIN** | **Yes** | Left ADC ← phone line 1 (AG1170 **VOUT** via **100 nF**) |
| **19** | **RLINEIN** | **Yes** | Right ADC ← phone line 2 (AG1170 **VOUT** via **100 nF**) |
| **18** | **MICIN** | No | Mono mic input (AC coupled) |
| **17** | **MICBIAS** | No | Bias for electret mic (~2.2 kΩ to AGND when used) |

**LLINEIN** / **RLINEIN** are **AC-coupled** inputs in the reference design (bias network inside chip uses **VMID**).

## Bias / reference

| Pin | Name | Connection |
|-----|------|------------|
| **16** | **VMID** | **~1 µF** (often 1 µF || 0.1 µF) from **VMID** to **AGND** — mid-rail reference for analog inputs |

Do not drive VMID from an external supply; it is an internal analog reference node.

## Rotary phone gateway — summary

### Wire these

| Function | WM8731 pins |
|----------|-------------|
| I²S to ESP32 | 3, 4, 5, 6, 7 (5↔7 tied), 25 (MCLK or crystal) |
| I²C to ESP32 | 23, 24, 21→GND, 22 strap |
| Power | 1, 8, 14 → +3V3; 27 → 1.8 V LDO; 15, 28, 11 → GND; 16 → cap to AGND |
| To SLIC (line 1) | 12 → VIN, 20 ← VOUT |
| To SLIC (line 2) | 13 → VIN, 19 ← VOUT |

### Can leave unconnected (this build)

| Pins | Names |
|------|--------|
| 2 | CLKOUT |
| 9, 10 | LHPOUT, RHPOUT (HPVDD/HPGND still tied) |
| 17, 18 | MICBIAS, MICIN |
| 26 | XTO (unless crystal on 25) |

### Passives still to add on PCB (not on schematic)

- **100 nF** AC coupling: LOUT, ROUT, LLINEIN, RLINEIN to AG1170  
- **100 nF** (or datasheet values) decoupling on AVDD, DBVDD, DCVDD, HPVDD  
- **1.8 V LDO** input +3V3 → output → DCVDD (27)  
- **4.7 kΩ** on I²C SDA/SCL to +3V3  
- Optional **33–100 Ω** series on I²S lines for SI

## Stereo mapping for two phone lines

| Channel | DAC (to phone) | ADC (from phone) | AG1170 |
|---------|----------------|------------------|--------|
| **Left** | **LOUT** (12) | **LLINEIN** (20) | Line 1 |
| **Right** | **ROUT** (13) | **RLINEIN** (19) | Line 2 |

One WM8731 is enough for **two** RJ11 lines; **MICIN** is not a third independent line pair.

## AG1170 SLIC GPIO (ESP32-C6)

Control lines from each **AG1170** to the ESP32-C6 (see `SIGNAL_LEVELS.md` for levels and timing). **SHK** is an input; **F/R**, **RM**, and **PD** are outputs to the SLIC.

| Signal | Direction | Line 1 | Line 2 |
|--------|-----------|--------|--------|
| **SHK** | SLIC → ESP32 | **GPIO1** | **GPIO19** |
| **F/R** | ESP32 → SLIC | **GPIO2** | **GPIO21** |
| **RM** | ESP32 → SLIC | **GPIO3** | **GPIO20** |
| **PD** | ESP32 → SLIC | **GPIO14** | **GPIO18** |

Do not use **GPIO8**, **GPIO9**, or **GPIO15** for SLIC — they are boot/JTAG strapping pins. Keep **GPIO16** / **GPIO17** (UART0) and **GPIO12** / **GPIO13** (USB) available for programming and debug.
